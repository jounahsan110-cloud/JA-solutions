# JA Solution website

A simple website made with only HTML, CSS and JavaScript. No tools or installs needed.

## Files
- `index.html` - the page
- `style.css` - the design
- `script.js` - menu, form, animations
- `favicon.svg` - browser tab icon
- `logo.png` - **add your logo here** (see below)

## Add your logo
Put your logo file in the **same folder as index.html** and name it `logo.png` (`logo.svg`, `logo.webp` or `logo.jpg` also work). It shows automatically in the header and footer. Until then, the text "JA Solution" is shown. Use a logo that is visible on a dark background.

## Upload to GitHub Pages (step by step)
1. Unzip the ZIP file on your computer.
2. On github.com, open your repository (or click **New** to create one).
3. Click **Add file > Upload files**.
4. Open the unzipped folder and drag **the files inside it** (not the folder itself) into the page. You should see `index.html` listed directly.
5. Click **Commit changes**.
6. Go to **Settings > Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
7. Wait 1 to 3 minutes. Your site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

If you see a 404, check that `index.html` is on the repository's front page, not inside a folder.

## Change contact details
WhatsApp and Instagram links are in `index.html`. The form number is at the top of `script.js`.
